# Brook Website Design System

Public, AI-readable technical reference for the Brook Fountains website.

**Visual / editable master:** [Brook Website Design System — Google Docs](https://docs.google.com/document/d/1Byfuv3h6QF3E6xd-6aK4TagfQm1CUAfi83MmwBM-k8M/edit)

## Files
- [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) — design rules, colors, gradients, responsive typography and approval status.
- [tokens.json](tokens.json) — structured design tokens for AI and developers.
- [CLAUDE.md](CLAUDE.md) — Claude Code instructions.
- [AGENTS.md](AGENTS.md) — general coding agent guidance.
- [CHANGELOG.md](CHANGELOG.md) — change history.

## How to use
Share the repository URL with an AI that can read public GitHub, or provide these files directly. External URL access depends on the AI system.

The Google Doc is the editable decision master; this GitHub repository is a **manually maintained technical mirror**. There is no automatic sync.

The Brook storefront codebase is separate: `pet-amazing/brook-site`. Do not change it without explicit permission. Never add secrets, customer data or private client materials to this public repository.
